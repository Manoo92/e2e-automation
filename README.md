🎭 Playwright E2E Test Suite
Node.js Playwright E2E
End-to-end test automation suite built with Playwright.

## Prerequisites
- Node.js v18 or higher
- npm or yarn

## Getting Started
Clone the repo and install dependencies:

git clone https://github.com/your-username/e2e-automation.git
cd e2e-automation
npm install
Install Playwright browsers:

npx playwright install
